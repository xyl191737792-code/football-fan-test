# 足彩人格小测试 H5

这是一个单文件静态 H5，入口为 `index.html`。

## 已实现

- 15 道单选题，带进度、返回和完成状态
- 4 类足彩玩家人格结果与可视化评分
- 结果链接分享：将答案编码在 URL hash 中，打开链接即可恢复结果
- 二维码：结果页调用 QR Server 生成二维码
- 本地数据收集：最近一次答题记录写入 `localStorage`
- 数据导出：结果页可下载 JSON 答题记录
- 移动端优先布局，适配桌面宽屏

## 发布到公网

在可以访问网络的终端中任选静态托管平台：

1. 将 `index.html` 上传到 Vercel、Netlify、Cloudflare Pages 或 GitHub Pages。
2. 开启 HTTPS（上述平台默认提供）。
3. 用发布后的 URL 打开页面，完成测试后点击“复制链接”或“查看二维码”。

当前 Codex 沙箱无法访问本机钥匙串，妙搭 CLI 因此不能创建应用或推送发布；也无法绑定本地端口做浏览器自动化验收。代码本身不依赖构建工具，上传单文件即可运行。
