# 足球迷人格小测试 H5

这是一个单文件静态 H5，入口为 `index.html`，无需构建工具即可运行。

## 已实现

- 15 道单选题，支持进度展示、返回修改、末题“查看人格”
- 6 类足球人格结果，每种人格拥有独立色彩、角色插画、关键词和能力评分
- 动态足球主题 UI：球场纹理、卡片浮动、进度动画和结果页主题切换
- 分享结果：答案编码在 URL hash 中，打开分享链接即可直接恢复结果
- 分享面板：优先调用系统分享，不可用时提供链接分享、扫码分享与手动复制
- 二维码：结果页调用 QR Server 生成二维码，支持遮罩点击、Esc 关闭和加载失败提示
- 本地记录：最近一次完整答题结果写入 `localStorage`
- 数据导出：结果页保留“导出答题数据”按钮，实际下载 PNG 海报
- 内置浏览器适配：手机或 App 内打开时改为原尺寸 PNG 预览，并按环境提供系统保存图片、复制图片和打开原图入口，避免触发外部下载器
- 基础可访问性：语义化状态、进度条、键盘焦点、选项方向键操作、按钮禁用态和无脚本提示
- 数据校验：恢复分享链接与导出前校验答案完整性，避免异常数据直接渲染
- 移动端优先布局，适配桌面宽屏、小屏设备和安全区

## 发布到公网

将 `index.html` 上传到 GitHub Pages、Vercel、Netlify 或 Cloudflare Pages 即可。页面使用 QR Server 提供二维码图片服务，正式部署时建议通过 HTTPS 访问，以便系统分享与复制链接体验更稳定。
